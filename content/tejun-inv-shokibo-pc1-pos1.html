  1. 1

    申請マイページにログインする

    申請マイページを開く

    推奨環境

    Windows の Microsoft Edge / Google Chrome の最新版での利用を推奨しています。

    申請マイページログイン画面で、紫色の GビズIDログイン を押します。

    GビズIDのログイン画面で、申請時に使ったアカウント情報を入力します。

    1. アカウントID（メールアドレス）を入力する
    2. パスワードを入力する
    3. ログイン を押す

    認証方法選択画面で、アプリ認証を行う を押します。

    ポイント

    設定済みの認証方法のみ選択できます。スマホアプリに通知が届きます。

    PC画面に表示された4桁の認証コードを、GビズIDアプリへ入力します。

    1. スマホの通知（またはアプリ）で「はい」を押す
    2. PCに表示されている認証コードを入力する
    3. 「認証する」を押す
    通知が届かないとき

    GビズIDアプリを手動で起動し、認証コードを入力してください。

    アプリに「ログインが完了しました」と表示されたら完了です。申請マイページが表示されます。

    ログイン後、次のメニューへ進みます。

    申請者メニュー→実績報告情報編集
  2. 2

    2. 動画を視聴したら「戻る」で説明画面に戻る
    3. 「動画を視聴して…理解しました。」にチェックを入れる

  11. 11

    口座情報を入力する

    添付したPDFを開き、画面の項目へ入力します。

    口座名義は事前確認を

    金融機関登録の名義と完全一致が必要です（スペース・濁点に注意）。必ず事前に金融機関へご確認ください。

    項目入力方法
    金融機関名PDFを開く → 下へスクロール → 紫色の「検索」ボタンをクリック → 全角カナで入力 → 余白クリック →「検索」→ 選択
    文字入力中は「検索」が押せません
    支店名金融機関名と同じ手順で検索・選択
    口座名義（カナ）金融機関登録の名義と完全一致で入力（スペース・濁点に注意）
    口座名義変換ツール

    次へ

    実績報告入力を完了する

    実績報告入力完了

    ここまでで①は完了

    添付・入力内容が一覧表示されます。金額を含め、すべて確認してください。

    注意

    修正が必要な場合は「戻る」で対応できます。

    戻る 次へ

  3. 3

    SMS認証コードを発行・入力する

    1. 「認証コードを発行する」を押す
    2. SMSで届いた4桁のコードを入力する
    有効期限

    認証コードは発行から30分間有効です。30分以内に提出まで完了してください。

    認証コードを発行する

  4. 4

    事務局へ提出する

    認証コード入力後、「事務局へ提出」を押します。

    事務局へ提出

    提出完了

    この画面が表示されれば完了です。その後、事務局による確定検査が行われます。

    差し戻し時

    不備がある場合は事務局から連絡があります。速やかに対応してください。
